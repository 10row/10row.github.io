A 10ROW operating system

Milo keeps the work moving.

Milo is a local company workspace built around one mission and one persistent Codex Director. It chooses useful next work, preserves context, verifies results, waits for real signals, and asks the user only for actions that cannot safely be delegated.

Contact Milo support Read the Gmail data policy
One clear mission

The Director owns the goal and adapts its plan as evidence changes. The user does not operate an agent hierarchy.

Real work, not activity

Files, account observations, outside effects, and claimed outcomes require inspectable receipts.

Independent account lanes

Each connected Gmail identity has its own encrypted authorization and exact identity check. Adding one account never replaces another.

Human control where it matters

Passwords, MFA, legal facts, payments, and consequential approvals stay with the person who owns them.

Google account access

Milo requests read-only Gmail access only when a user chooses to connect a mailbox. It uses that access to observe messages relevant to the user’s visible project work. Milo cannot send, edit, or delete Gmail messages through this connection.

Relevant message metadata or excerpts may be supplied to the AI worker configured for that project. Milo does not sell Gmail data, use it for advertising, or use it to train a general AI model. Users can disconnect and revoke an account at any time.
